Flexbox & CSS Grid Mastery ⭐ EXAM FOCUS

⚠ Exam important — must know

Flexbox is explicitly called out by your teacher. Know the container vs item properties cold.

01Flexbox — Container Properties

activate flexbox on the parent 
.container {
  display: flex;              /* enables flexbox */
  flex-direction: row;         /* row | column | row-reverse | column-reverse */
  justify-content: center;    /* main axis — flex-start | flex-end | center | space-between | space-around | space-evenly */
  align-items: center;        /* cross axis — flex-start | flex-end | center | stretch | baseline */
  flex-wrap: wrap;            /* nowrap | wrap | wrap-reverse */
  gap: 16px;                  /* space between items */
}

justify-content (main axis)

flex-start Items pack to start
flex-end Items pack to end
center Items centered
space-between Equal space between items
space-around Equal space around items
space-evenly Equal space everywhere

align-items (cross axis)

flex-start Top of container
flex-end Bottom of container
center Vertically centered
stretch Fill height (default)
baseline Align text baselines

02Flexbox — Item Properties

these go on the children 
.item {
  flex: 1;                 /* shorthand for flex-grow flex-shrink flex-basis */
  flex-grow: 1;            /* how much item grows to fill space */
  flex-shrink: 0;          /* 0 = won't shrink below flex-basis */
  flex-basis: 200px;       /* starting size before free space is distributed */
  align-self: flex-end;    /* override align-items for THIS item */
  order: 2;                /* default is 0, can be negative */
}

03Centering Everything with Flexbox

The most common flex trick: perfectly center a child both horizontally and vertically. 
.parent {
  display: flex;
  justify-content: center;  /* horizontal */
  align-items: center;      /* vertical */
  height: 100vh;
}

04CSS Grid — Container Properties 

.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;   /* 3 cols: 25% 50% 25% */
  grid-template-columns: repeat(3, 1fr); /* same thing */
  grid-template-rows: 100px auto;       /* row heights */
  gap: 20px;                            /* row-gap + column-gap */
  justify-items: center;               /* align content in cells horizontally */
  align-items: center;                 /* align content in cells vertically */
}

05CSS Grid — Item Properties

.item {
  grid-column: 1 / 3;    /* span from col line 1 to 3 (= span 2 cols) */
  grid-column: span 2;   /* same: span 2 columns */
  grid-row: 1 / 3;       /* span 2 rows */
  justify-self: end;     /* override for this one item */
  align-self: start;
}

06Flexbox vs Grid — When to Use Which

Use Flexbox when…

  • 1D layout — items in a single row or column
  • Navigation bars
  • Centering one element
  • Distributing items dynamically
  • Card rows that can wrap

Use Grid when…

  • 2D layout — rows AND columns simultaneously
  • Full page layouts
  • Dashboard/magazine grids
  • Items that must align in both directions
  • Complex overlapping layouts

03Arrays — Creating & Manipulating 

const fruits = ["apple", "banana", "mango"];

fruits[0];            // "apple"  (0-indexed)
fruits.length;        // 3
fruits.push("grape");  // add to END → ["apple","banana","mango","grape"]
fruits.pop();         // remove from END → "grape"
fruits.unshift("kiwi");// add to START
fruits.shift();       // remove from START
fruits.includes("mango"); // true
fruits.indexOf("banana"); // 1

04Nesting — Objects in Arrays in Objects 

// Deeply nested structure
const company = {
  name: "TechCorp",
  departments: [              // array of objects
    {
      dept: "Engineering",
      employees: [          // nested array
        { name: "Bilal", salary: 220000 },
        { name: "Ayesha", salary: 180000 },
      ]
    }
  ]
};

// Accessing nested data
company.name;                              // "TechCorp"
company.departments[0].dept;             // "Engineering"
company.departments[0].employees[1].name; // "Ayesha"
Rule of thumb: [] means "give me index N of an array", . means "give me property X of an object". Chain them to drill down any depth.

Arrow Functions, Map & Filter ⭐ EXAM FOCUS

⚠ Exam important

Arrow functions, map, filter, and reduce are explicitly in the assignment AND called out as exam topics. Know these cold.

01Arrow Functions

// Regular function
function add(a, b) { return a + b; }

// Arrow function — equivalent
const add = (a, b) => a + b;        // implicit return (no {})  

// With body (explicit return needed)
const greet = (name) => {
  const msg = `Hello, ${name}!`;
  return msg;
};

// Return object literal — wrap in ()
const makeCard = (name) => ({ displayName: name.toUpperCase() });

// Default parameter
const sayHi = (name = "Guest") => `Hi ${name}`;
sayHi();          // "Hi Guest"
sayHi("Bilal");  // "Hi Bilal"

02map() — Transform Every Element

map takes an array, applies a function to EVERY item, and returns a new array of the same length. Never mutates original. 
const numbers = [1, 2, 3, 4];

// Double every number
const doubled = numbers.map(n => n * 2);
// [2, 4, 6, 8]

// Real-world: transform objects
const employees = [
  { name: "Ayesha", salary: 180000 },
  { name: "Bilal", salary: 220000 },
];

const cards = employees.map(emp => ({
  displayName: emp.name.toUpperCase(),
  formattedSalary: `Rs. ${emp.salary.toLocaleString()}`,
}));
// [{displayName:"AYESHA", ...}, {displayName:"BILAL", ...}]

03filter() — Keep Only Matching Items

filter returns a new array containing only items where the callback returns true. Length can be shorter. 
const numbers = [1, 2, 3, 4, 5, 6];

// Keep only even numbers
const evens = numbers.filter(n => n % 2 === 0);
// [2, 4, 6]

// Real-world: filter employees
const engineers = employees.filter(emp => emp.department === "Engineering");
const highPerformers = employees.filter(emp => emp.rating >= 8);
const activeOnly = employees.filter(emp => emp.active === true);

// Chaining: active engineers
const activeEngineers = employees
  .filter(e => e.active && e.department === "Engineering")
  .map(e => e.name);
// ["Ayesha Khan", "Bilal Ahmad"]

04reduce() — Combine Into Single Value

reduce processes every item and accumulates a single result (number, string, object, etc.). 
// Signature: array.reduce((accumulator, currentItem) => ..., initialValue)

// Sum all salaries
const totalPayroll = employees.reduce((sum, emp) => sum + emp.salary, 0);

// Average rating
const avgRating = (employees.reduce((sum, emp) => sum + emp.rating, 0)
  / employees.length).toFixed(2);

// Group by department (object accumulator)
const byDept = employees.reduce((acc, emp) => {
  acc[emp.department] = (acc[emp.department] || 0) + 1;
  return acc;
}, {});
// { Engineering: 3, Marketing: 2, Sales: 2, Design: 1 }

05find, some, every, sort

// find — returns FIRST match (or undefined)
const zara = employees.find(e => e.name === "Zara Iqbal");

// some — true if ANY match
const hasPerfect = employees.some(e => e.rating === 10); // true

// every — true if ALL match
const allValid = employees.every(e => e.salary > 0);    // true

// sort — ALWAYS sort a COPY with [...arr]
const bySalary = [...employees].sort((a, b) => b.salary - a.salary); // desc
const byName = [...employees].sort((a, b) => a.name.localeCompare(b.name));
⚠ Never sort the original array! Always do [...arr].sort(). And always pass a comparator for numbers — otherwise JS sorts as strings!

Spread, Rest, Destructuring, Deep vs Shallow Copy

01Spread Operator ...

Spread "unpacks" an array or object into individual elements. 
// ── Arrays ──
const a = [1, 2, 3];
const b = [4, 5];
const combined = [...a, ...b];       // [1,2,3,4,5]
const copy = [...a];                  // shallow copy of a

// ── Objects ──
const defaults = { color: "blue", size: "md" };
const custom = { ...defaults, color: "red" }; // override color
// { color: "red", size: "md" }

// ── In function calls ──
Math.max(...[5, 2, 9, 1]);          // 9

02Rest Parameters ...args

Rest collects "the rest of the arguments" into an array. Goes in the function signature. 
// Collects all arguments into 'lines' array
const logSection = (title, ...lines) => {
  console.log(title);
  lines.forEach(line => console.log(line));
};

logSection("DEMO", "line 1", "line 2", "line 3");
// title = "DEMO"
// lines = ["line 1", "line 2", "line 3"]

03Destructuring

Object Destructuring 
const emp = { name: "Ayesha", dept: "Eng", salary: 180000 };

// Extract into variables
const { name, dept } = emp;
// name = "Ayesha", dept = "Eng"

// Rename while destructuring
const { name: empName, salary: pay } = emp;
// empName = "Ayesha", pay = 180000

// Default values
const { city = "Lahore" } = emp;
// city = "Lahore" (since emp.city is undefined)
Array Destructuring 
const colors = ["red", "green", "blue"];

const [first, second] = colors;
// first = "red", second = "green"

// Skip elements with comma
const [,, third] = colors;
// third = "blue"

// Rest in arrays
const [head, ...tail] = colors;
// head = "red", tail = ["green","blue"]

// Swap variables
let x = 1, y = 2;
[x, y] = [y, x]; // x=2, y=1

04Deep vs Shallow Copy

⚠ Critical concept: Objects and arrays are reference types. Assigning them does NOT copy — it shares the reference! 
// ── SHALLOW COPY ──
// Works fine for flat (non-nested) objects
const original = { name: "Ayesha", score: 9 };
const shallowCopy = { ...original };      // or Object.assign({}, original)
shallowCopy.name = "Bilal";
original.name;  // still "Ayesha" ✓

// ── SHALLOW COPY PROBLEM ──
// Nested objects still share reference!
const a = { info: { city: "Lahore" } };
const b = { ...a };         // shallow copy
b.info.city = "Karachi";
a.info.city;                 // "Karachi" ← mutated! ✗

// ── DEEP COPY ──
// JSON trick (simple, loses functions/Dates)
const deepCopy = JSON.parse(JSON.stringify(a));
deepCopy.info.city = "Islamabad";
a.info.city;   // still "Karachi" ✓ — original untouched

// Modern: structuredClone (best option)
const deepCopy2 = structuredClone(a);

Shallow Copy Methods

  • {...obj} — object spread
  • [...arr] — array spread
  • Object.assign({}, obj)
  • arr.slice()
  • Good for: flat structures (no nesting)

Deep Copy Methods

  • structuredClone(obj) — modern & best
  • JSON.parse(JSON.stringify(obj)) — simple but loses functions/Dates
  • Lodash _.cloneDeep(obj) — library
  • Good for: nested objects/arrays

// === find: Lookup by Name ===
const lookupName = "Zara Iqbal";
const foundEmployee = employees.find(e => e.name === lookupName);
logSection(
  "LOOKUP BY NAME (find)",
  foundEmployee
    ? `Found: ${foundEmployee.name} — ${foundEmployee.department}, ${formatSalary(foundEmployee.salary)}`
    : `No employee named "${lookupName}" was found.`
);

// === some / every: Boolean Checks ===
const hasPerfectScorer = employees.some(e => e.rating === 10);
const allSalariesValid = employees.every(e => e.salary > 0);
logSection(
  "BOOLEAN CHECKS (some / every)",
  `Any employee with rating === 10? ${hasPerfectScorer ? "Yes" : "No"}`,
  `All salaries greater than 0? ${allSalariesValid ? "Yes" : "No"}`
);

// === reduce: Aggregate Values ===
const totalPayroll = employees.reduce((sum, emp) => sum + emp.salary, 0);
const averageRating = (employees.reduce((sum, emp) => sum + emp.rating, 0) / employees.length).toFixed(2);
const departmentBreakdown = employees.reduce((acc, emp) => {
  acc[emp.department] = (acc[emp.department] || 0) + 1;
  return acc;
}, {});
logSection(
  "AGGREGATES (reduce)",
  `Total monthly payroll: ${formatSalary(totalPayroll)}`,
  `Average rating: ${averageRating}/10`,
  `Department breakdown: ${JSON.stringify(departmentBreakdown)}`
);

// === sort: Two Criteria (always on a COPY) ===
const bySalary = [...employees].sort((a, b) => b.salary - a.salary);
const byName   = [...employees].sort((a, b) => a.name.localeCompare(b.name));

logSection("SORTED BY SALARY — DESC (sort, copy)");
bySalary.forEach((emp, i) =>
  console.log(`${i + 1}. ${emp.name.padEnd(18)} ${formatSalary(emp.salary)}`)
);
logSection("SORTED BY NAME — ASC (sort, copy)");
byName.forEach((emp, i) =>
  console.log(`${i + 1}. ${emp.name.padEnd(18)} (${emp.department})`)
);
console.log("\nOriginal order preserved? " + (employees[0].name === "Ayesha Khan"));

// === Chained Pipelines ===
const engineerRankingReport = employees
  .filter(e => e.active && e.department === "Engineering")
  .slice()
  .sort((a, b) => b.rating - a.rating)
  .map((emp, i) => `#${i + 1} ${emp.name} — ${formatRating(emp.rating)}`);

logSection("PIPELINE 1: Active Engineer Ranking", ...engineerRankingReport);

const topEarnerCards = employees
  .filter(e => e.rating >= 8)
  .slice()
  .sort((a, b) => b.salary - a.salary)
  .map(e => ({
    name: e.name, department: e.department,
    salary: formatSalary(e.salary), rating: formatRating(e.rating)
  }));

logSection("PIPELINE 2: Top Earners Among High Performers");
topEarnerCards.forEach(card => console.log(card));

// === Final Summary ===
const topPerformer = [...employees].sort((a, b) => b.rating - a.rating)[0];
logSection(
  "FINAL SUMMARY",
  `Total employees: ${employees.length}`,
  `Active employees: ${activeEmployees.length}`,
  `Departments: ${Object.keys(departmentBreakdown).join(", ")}`,
  `Total payroll: ${formatSalary(totalPayroll)}`,
  `Average rating: ${averageRating}/10`,
  `Highest paid: ${bySalary[0].name} (${formatSalary(bySalary[0].salary)})`,
  `Top performer: ${topPerformer.name}`
);

console.log("\nAll checks complete. Assignment 11 reference solution finished.\n");

EXAM Q2

Arrow Methods — reduce, map, filter

Quick Cheat: map vs filter vs reduce

At a Glance

Method Input → Output Use when you want to…
map [n] → [n] same length Transform every item
filter [n] → [≤n] shorter Keep only matching items
reduce [n] → single value Sum, count, group, etc.
find [n] → 1 item or undefined Get first match
some [n] → boolean Check if any match
every [n] → boolean Check if all match
all three together in a pipeline 
const data = [
  { name: "Ali", score: 85, passed: true },
  { name: "Sara", score: 40, passed: false },
  { name: "Usman", score: 92, passed: true },
];

// 1. filter — only passed students
const passed = data.filter(s => s.passed);

// 2. map — get their names
const names = passed.map(s => s.name);
// ["Ali", "Usman"]

// 3. reduce — total score of passed students
const total = passed.reduce((sum, s) => sum + s.score, 0);
// 177

// All in one chain:
const avgPassScore = data
  .filter(s => s.passed)
  .reduce((sum, s, _, arr) => sum + s.score / arr.length, 0);
// 88.5

EXAM Q5

JSON File — Extract Data

What is JSON?

JSON (JavaScript Object Notation) is a text format for storing/sharing data. It looks like a JS object but with strict rules: keys must be in double quotes.

JSON Syntax Rules

Valid JSON

{
  "name": "Ayesha",
  "age": 25,
  "active": true,
  "scores": [90, 85, 92],
  "address": {
    "city": "Lahore"
  }
}

JSON Rules

  • Keys must use double quotes
  • Strings must use double quotes
  • No trailing commas after last item
  • No comments allowed
  • Values: string, number, boolean, null, array, object
  • No functions or undefined

Parsing & Extracting from JSON

// ── JSON string → JS object ──
const jsonString = '{"name":"Ayesha","salary":180000,"scores":[90,85,92]}';
const obj = JSON.parse(jsonString);

// Extract values
obj.name;           // "Ayesha"
obj.salary;         // 180000
obj.scores[0];      // 90

// ── JS object → JSON string ──
const person = { name: "Bilal", age: 30 };
const json = JSON.stringify(person);
// '{"name":"Bilal","age":30}'

// Pretty-print (2 spaces indent)
JSON.stringify(person, null, 2);

Extracting from Nested/Array JSON — Like the Exam

// Suppose this is the JSON given in the exam:
const data = {
  "company": "TechCorp",
  "employees": [
    { "name": "Ayesha", "dept": "Engineering", "salary": 180000 },
    { "name": "Bilal",  "dept": "Engineering", "salary": 220000 },
    { "name": "Sana",   "dept": "Marketing",   "salary": 120000 }
  ]
};

// Extract company name
data.company;                        // "TechCorp"

// Extract first employee's name
data.employees[0].name;              // "Ayesha"

// All employee names
const names = data.employees.map(e => e.name);
// ["Ayesha", "Bilal", "Sana"]

// Only engineering employees
const engineers = data.employees.filter(e => e.dept === "Engineering");

// Total salary
const total = data.employees.reduce((sum, e) => sum + e.salary, 0);
// 520000
Pattern to remember: JSON.parse() to read/extract. JSON.stringify() to save/send. Once parsed, use normal .map(), .filter(), dot notation to extract anything.
